## Catatan kualitas sumber
- Sebagian besar sumber adalah **blog/galeri pihak ketiga** dan halaman marketing tool. Angka (jumlah video,
  view, tanggal rilis) adalah klaim sumber dan belum diverifikasi.
- Label **[umum]** di katalog = pengetahuan desain umum yang tidak ditemukan sumbernya dalam riset ini
  (mis. Brutalist, Synthwave, Collage). Perlu riset lanjutan kalau mau dijadikan acuan.
- Beberapa halaman (pasqualepillitteri.it, learnwithmeai.com, motionformat.com) tidak bisa dibuka dari sesi cloud ini karena
  pembatasan jaringan; isinya dikutip dari ringkasan hasil pencarian.
